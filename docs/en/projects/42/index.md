# 42 projects

A selection of the projects I built at School 42 — from binary exploitation to DevOps infrastructure, by way of full-stack web development.

- [**Boot2Root**](/en/projects/42/boot2root) — CTF: fully compromising a machine up to root.
- [**Rainfall**](/en/projects/42/rainfall) — SUID binary exploitation and privilege escalation.
- [**Snowcrash**](/en/projects/42/snowcrash) — a chain of Linux vulnerabilities exploited in cascade.
- [**Inception of Things**](/en/projects/42/inception-of-things) — a Kubernetes infrastructure in GitOps.
- [**ft_nm**](/en/projects/42/ft_nm) — reimplementing `nm` and parsing the ELF format.
- [**ft_transcendence**](/en/projects/42/ft_transcendence) — a real-time web app around Pong.
- [**Taskmaster**](/en/projects/42/taskmaster) — a process manager in Python.
