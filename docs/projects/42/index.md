# Projets 42

Une sélection des projets que j'ai réalisés à l'École 42 — de l'exploitation de binaires à l'infrastructure DevOps, en passant par le développement web full-stack.

- [**Boot2Root**](/projects/42/boot2root) — CTF : compromission complète d'une machine jusqu'à root.
- [**Rainfall**](/projects/42/rainfall) — exploitation de binaires SUID et élévation de privilèges.
- [**Snowcrash**](/projects/42/snowcrash) — chaîne de vulnérabilités Linux exploitées en cascade.
- [**Inception of Things**](/projects/42/inception-of-things) — infrastructure Kubernetes en GitOps.
- [**ft_nm**](/projects/42/ft_nm) — réimplémentation de `nm` et parsing du format ELF.
- [**ft_transcendence**](/projects/42/ft_transcendence) — application web temps réel autour d'un Pong.
- [**Taskmaster**](/projects/42/taskmaster) — gestionnaire de processus en Python.
