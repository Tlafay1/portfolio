# 2ez

## Description

2ez est une application web de motivation personnelle, écrite en **Django** (backend) et **Vue** (frontend). Elle est en production, hébergée sur **Google Cloud**, et accessible à l'adresse [2-ez.fr](https://2-ez.fr).

## Pourquoi ce projet compte

2ez est mon terrain de jeu full-stack : j'y ai construit et déployé une application complète, du modèle de données jusqu'à la mise en ligne. C'est aussi ce qui rend mon profil pentest différent — je sais ce que c'est que de **concevoir et exploiter une vraie application** :

- **Backend** — API en Django, gestion des utilisateurs et de l'authentification (Firebase).
- **Frontend** — interface en Vue/TypeScript.
- **Infrastructure** — déploiement et hébergement sur Google Cloud, chaîne d'intégration et de déploiement.

Quand j'audite une application, cette expérience de développeur me permet de comprendre immédiatement les choix d'architecture — et donc où chercher les failles.
